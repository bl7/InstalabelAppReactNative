# Official Xprinter Android SDK

Source: Xprinter `printer-lib-3.2.0.aar` (POSConnect / TSPLPrinter)

Used by `com.instalabel.xprinter.XprinterPrintBridge` for Born4ship / Xprinter
label printers (e.g. DB403): connect over Bluetooth, rasterize InstaLabel TSPL
layouts via `TsplRasterizer`, print with `TSPLPrinter.bitmap(...)`.
