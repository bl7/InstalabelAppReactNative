# Official Rongta RTPrinterSDK

Source: Thermal Printer & Label Printer Android SDK
Version bundled: PrinterExample_standard_v2.2.04_2026.05.11

- `printer_library.jar` — RTPrinterSDK
- `jniLibs/**/libserial_port.so` — serial native lib (USB/COM)
- `doc/Android_printer_library_Manual_v1.0.0.pdf` — official manual

Used by `com.instalabel.rongta.RongtaPrintBridge` for ZPL label printing via `ZplFactory.getBitmapCmd`.
