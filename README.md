# InstaLabel Mobile App

A React Native mobile application for InstaLabel functionality.

## Features

- Bluetooth printer connectivity
- Label printing and management
- Offline support
- Custom label creation

## Getting Started

### Prerequisites

- Node.js (>=18)
- React Native development environment
- Android Studio (for Android development)

### Installation

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run on Android:
   ```bash
   npx react-native run-android
   ```

## Development

This project uses React Native 0.73.0 and targets Android devices.
